# Python Weather App 🌦️

## About

A Python-based Weather App that fetches real-time weather information for different cities using the OpenWeatherMap API. It displays temperature, humidity, weather conditions, and wind speed.

## Features

- Search weather by city name
- Real-time weather data
- Temperature in Celsius (°C)
- Humidity information
- Weather condition descriptions
- Wind speed details
- API error handling
- Simple command-line interface

## Technologies Used

- Python 3
- OpenWeatherMap API
- Requests
- Python-dotenv

## Installation & Setup

**1. Clone the repository**

```bash
git clone https://github.com/chavanaditya872-blip/Python-Weather-App.git
```

**2. Navigate to the project folder**

```bash
cd Python-Weather-App
```

**3. Install dependencies**

```bash
pip install -r requirements.txt
```

**4. Configure API Key**

Create a `.env` file in the project folder:

```env
OPENWEATHER_KEY=your_api_key_here
```

Get your API key from [OpenWeatherMap](https://openweathermap.org/api).

**5. Run the application**

```bash
python main.py
```
